List of supported commands

| Commands               | Usages                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| a = 1 2 3 \| a = 1,2,3 | Used to create vectors — Space's or commas can be used to separate the numbers for calculation |
| a                      | This will list that vectors values *If it has been assigned already*                           |
| a + b                  | This will add the values of the two Vectors                                                    |
| a - b                  | This will subtract the values of the two vectors                                               |
| a * 2.5                | This will scale the values of the vector using a defined constant                              |
| a . b                  | This will dot product the two vectors                                                          |
| a x b                  | This will cross priduct the two vectors                                                        |
| list                   | This will list all defined vectors                                                             |
| clear                  | This will clear all defined vectors                                                            |
| help                   | This will present a help menu to present calculator formatting / or commands                   |
| quit / exit            | This will exit the program, and clear memory. Either quit or exit will close the program       |
